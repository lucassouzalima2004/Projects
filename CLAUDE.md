# Projects · central dos sites

**Regra: cada site novo ganha um repositório próprio** na conta `lucassouzalima2004`. Nunca crie um site novo dentro deste repositório.

- Para um site novo, siga a skill `.claude/skills/novo-site/` (também dá para chamar com `/novo-site`).
- `templates/site-repo/` é o modelo copiado para cada repositório novo: workflow de publicação no Cloudflare Pages, README e CLAUDE.md.
- A tabela "Sites" do `README.md` lista todos os sites e onde cada um está. Mantenha atualizada.
- `nail-studio/` é anterior a essa regra e continua aqui; serve de referência de estilo e estrutura para os próximos.
- Mudanças num site que já tem repositório próprio acontecem no repositório dele, não aqui.
- Fale com o usuário em português.
